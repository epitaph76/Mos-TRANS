# Ссылки для формы «Загрузка решения»

- Рабочая система из трёх модулей и запуск Docker: https://github.com/epitaph76/Mos-TRANS/tree/master
- Инструкция для жюри: https://мостранс.хелпи.рф/instructions
- Документация проекта: https://мостранс.хелпи.рф/docs
- Swagger API: https://мостранс.хелпи.рф/api

Текущий дашборд показывает живой NDTP с привязкой к маршруту. Исторические прогнозы и уровни риска доступны через API и на странице инструкции. Прогноз по новым NDTP-пакетам пока не реализован; не указывайте обратное в форме.

Метрики опубликованного test: MAE регрессии 55,90 с; Brier score вероятности опоздания более 120 с — 0,1334 на групповом holdout. Это не оценка работы на новом дне или на живом потоке.
